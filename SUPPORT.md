# Support

For connection instructions, start with the [integration guide](docs/integrations.md)
and its [troubleshooting section](docs/integrations.md#troubleshooting).

Use [GitHub issues](https://github.com/Syntropi-ai/o-plus-plus-mcp/issues) for
documentation mistakes or reproducible connection problems. Include:

- Your MCP client and version.
- The operation you tried, expected result and observed result.
- A redacted error message and steps to reproduce it.

Issues are public. Remove tokens, cookies, account details and private Space
content before posting. For account, billing or private-data questions, contact
[eng@syntropi.ai](mailto:eng@syntropi.ai) or visit
[O++ support](https://agent.syntropi.ai/support).

Report security concerns privately using [SECURITY.md](SECURITY.md).
