# Contributing

Suggestions, documentation fixes and client configuration examples are welcome.
Open an [issue](https://github.com/Syntropi-ai/o-plus-plus-mcp/issues) or a pull
request describing the problem and the proposed change. For integration
examples, name the client version and link its official documentation.

Keep examples focused on the hosted O++ endpoint and check that commands, links
and configuration are accurate. Use placeholders for personal details and
remove credentials and private content.

This repository contains connection material and optional skills. The hosted
server implementation is maintained separately.
